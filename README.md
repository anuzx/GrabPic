### Grabpic

backend -> `http://localhost:5000`

<br/>

frontend -> `http://localhost:3000`

<br/>

ai-service -> `http://localhost:8000`

### setup guide

1. `docker compose up -d` - in root folder
2. `bun run api`- in root folder
3. `uv run ai`- in root folder
4. `bun run dev` - in apps/web folder
